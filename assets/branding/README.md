# Atlas branding assets

- `atlas-logo.png` is the high-resolution transparent master used for project branding.
- `atlas-logo-readme.png` is the optimized 720 px-high transparent version embedded in the public README.

Use the detailed logo for documentation, repository profiles, release artwork,
and other large brand surfaces. Do not use it as a small interface icon or
favicon: its fine engraved details are not designed to remain legible at those
sizes. A dedicated simplified mark should be created for compact contexts.

Preserve the artwork's aspect ratio, colors, wordmark, and clear space. Do not
crop, recolor, distort, or place additional text over the logo.
